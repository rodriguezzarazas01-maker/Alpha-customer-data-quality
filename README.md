# Α Proyecto Alfa | Customer Data Quality

## Descripción

Store 1 planea implementar un programa de fidelización con el objetivo de comprender mejor a sus clientes y desarrollar campañas de marketing más personalizadas.

Antes de iniciar este proceso, fue necesario llevar a cabo una etapa de preparación, limpieza y validación de datos para garantizar que la información utilizada en futuros análisis fuera consistente, confiable y apta para la toma de decisiones.

## Objetivos

- Mejorar la calidad de los registros de clientes.
- Corregir inconsistencias en la información disponible.
- Estandarizar variables clave como nombres y edades.
- Consolidar información de consumo.
- Preparar la base de datos para futuras iniciativas de segmentación y fidelización.

## Herramientas utilizadas

- Python
- Jupyter Notebook
- Limpieza de datos
- Validación de datos
- Transformación de datos
